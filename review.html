01绪论：图像处理到底是什么INTRODUCTION

这一章内容少，优先掌握“三层关系”和系统组成，花 10 分钟即可建立框架。

1.1 图像与数字图像★★

定义图像：用各种观测系统（传感器），以不同的形式和手段观测客观世界（宏观、微观、介观）而获得的、可以直接作用于人眼并产生视知觉的实体。

数学上，图像表示成一个二维函数 f(x, y)：x、y 是空间坐标，f 在该点的数值是“性质”（灰度图像里是灰度，彩色图像里是颜色通道值）。数字图像就是把这个连续函数离散化——坐标离散（采样）、数值离散（量化）。一幅数字图像由许多像素（pixel）组成。

1.2 图像处理、图像分析、图像理解★★★

狭义的数字图像处理：输入和输出都是图像的处理（图像 → 图像）。比如去噪、锐化、增强。
广义的数字图像处理：包含图像处理、图像分析、图像理解三个层次。教材采用的正是这个框架。

层次输入→输出操作对象数据量抽象程度例子
图像处理
低层		图像 → 图像像素大低去噪、增强、锐化、几何校正
图像分析
中层		图像 → 数据目标（区域）中中分割、特征提取、测量、计数

记忆口诀越往上越“抽象”，越往下越“像素”。数据量从大到小，抽象程度/语义从低到高，操作对象依次是 像素 → 目标 → 符号。

1.3 数字图像处理系统的组成★★

一个通用图像处理系统包含 8 个部件，常见填空：

图像传感器→专用图像处理硬件→计算机→图像处理软件+大容量存储+显示器 / 硬拷贝+网络 / 云+问题域

其中“问题域”贯穿全局：指领域知识（医学/遥感/工业），它决定用什么算法、参数怎么设。

1.4 发展与应用（了解）★

  • 起源：最早用于报纸业（Bartlane 电缆图片传输系统）；20 世纪 60 年代计算机出现后，Ranger 7 拍摄月球图像；60 年代末～70 年代进入医学（CT）、遥感、天文。
  • 成像波段：伽马（核医学）、X 射线（CT/安检）、紫外、可见光、红外（测温）、微波（SAR）、射频（MRI）。

02数字图像基础DIGITAL IMAGE FUNDAMENTALS

这一章是全课程的基础计算来源：存储容量、图像中心、邻接判断、仿射矩阵都值得各练一遍。概念部分则是填空题的富矿。

2.1 图像感知与获取★

图像来源：“照射”源（电磁波、超声波）+ “场景”元素对光能的反射或吸收 → 光转换器 → 连续电压波形 → 数字化。

传感器有三种形态：单个（点扫描，如光电管）、条带（线阵，如扫描仪、推扫式卫星）、阵列（面阵，如 CCD/CMOS 相机）。

f(x, y) = i(x, y) · r(x, y)　　其中 0 < i(x,y) < ∞，0 ≤ r(x,y) ≤ 1(2.4)

i 是入射照射分量（取决于光源），r 是反射系数分量（取决于物体性质）。反射系数的典型值要记：黑天鹅绒 0.01、不锈钢 0.65、白墙面 0.80、白雪 0.93。反射率模型使 r 有界；数字图像再通过量化形成有限灰度范围。

2.2 采样与量化：数字化的两把刀★★★

过程离散化的是什么通俗理解决定什么
采样
Sampling		空间坐标在图像上打格子，只保留格子点上的值。格子越密，采样点越多。决定空间分辨率（M×N 的大小）
量化
Quantization		灰度值把连续的亮度值“四舍五入”到有限的档位。档位越多越细腻。决定灰度分辨率（比特数 k，级数 L=2k）

一幅 M 行 N 列、灰度级为 L=2k 的数字图像，可以写成矩阵，也可以写成传统形式 A。存储所需比特数为：

b = M × N × k　（比特）(2.12)
例一幅 1024×1024 的 8 比特灰度图像，占多少存储空间？若是 24 比特彩色图像呢？
灰度：b = 1024×1024×8 bit = 8 388 608 bit = 1 048 576 B = 1 MB。
彩色：每个像素 24 bit（RGB 各 8 bit），b = 1024×1024×24 bit = 3 MB。
速算技巧：1024×1024×8 bit 恰好 = 1 MB，记住这个基准，其他尺寸按比例缩放即可。

图像的中心

原点取 (0,0)、范围到 (M−1, N−1) 的 M×N 图像，其中心是把 M、N 分别除以 2 后四舍五入取整：

例1280×1024 的图像，中心在 (640, 512)；1281×1023 的图像，中心在 (641, 512)。
注意 1281/2 = 640.5 → 641，1023/2 = 511.5 → 512。这是作业 2-9 的考点。

2.3 空间分辨率与灰度分辨率★★★

概念定义降低后会怎样（必背现象）
空间分辨率图像空间中可分辨的最小细节，用单位长度上的像素数或线对数表示，单位 dpi（每英寸点数）出现棋盘（马赛克）效应，细节丢失、边缘呈方块
灰度分辨率灰度级中可分辨的最小变化，用比特数表示，通常为 2 的整数次幂（最常用 8 bit / 256 级）出现伪轮廓（山脊状结构），平滑渐变变成一层层色阶
易错“空间分辨率必须针对空间单位来规定才有意义。”两块都是 1920×1080 的屏，户外大屏尺寸大得多，所以它的 dpi（每英寸像素数）反而更低——像素个数相同 ≠ 分辨率相同。这是选择题的经典陷阱。
另一条：灰度级必须是 2 的整数次幂（8、10、12、16 bit），说“300 级灰度”是错的。

等偏爱曲线：主观质量相同的点在 N–k 平面上的连线。两条结论：① 质量一般随 N/k 增大而提高；② 细节丰富的图像可用较少灰度级表示（人眼对细节区的量化误差不敏感）。

2.4 图像插值★★

作用：用已知数据估计未知位置的数值。放大、缩小、旋转之后，新坐标往往落在原图的“格子之间”，必须靠插值补出灰度值。

方法怎么算效果与适用
最近邻直接取离它最近的那个原像素值最快；放大后有锯齿/块状
双线性用周围 4 个像素做两次线性加权平滑但略模糊；最常用
双三次用周围 16 个像素做三次插值边缘最平滑、细节最好，计算量最大

2.5 算术运算：加减乘除各自的用途★★★

使用条件：参与运算的图像大小必须相同；减法/除法还要求两幅图已配准（同一场景、同一视角）。

运算典型用途为什么有效
加多幅平均降噪、图像融合噪声随机且不相关，平均后噪声被“抵消”，信号被保留
减差异增强：血管造影、变化检测、运动检测相同部分相减为 0，只留下“变化/差异”
乘ROI 提取（掩膜 mask，ROI 内为 1、其余为 0）乘 1 保留、乘 0 抹掉
除光照不均校正、归一化把乘性的光照影响“除掉”

图像平均降噪的定量结论（高频）：设观测 g = f + η（η 零均值、各次同方差且不相关），对同一场景重复拍 K 次取平均：

ḡ(x,y) = f(x,y) + (1/K)·Σ ηi(x,y)　⟹　E[ḡ] = f，　σḡ = ση / √K(2.26–2.29)

也就是说：平均 K 幅，噪声标准差降为 1/√K。要降一半噪声需要 4 幅，降为 1/10 需要 100 幅。此法要求成像设备视场固定、场景静止（如天文摄影），否则会糊。

2.6 集合运算与逻辑运算★★

把二值图看成“前景像素的集合”，就有并（∪）、交（∩）、补、差（−）四种运算，其中 A − B = A ∩ Bc；对应逻辑运算或/与/非。用途：掩膜、形态学、模板比对（与“金标准”的补集做 AND，差异处为 1）。

2.7 几何变换（仿射变换）★★★

[x′; y′; 1] = A · [x; y; 1] = [[a11, a12, a13], [a21, a22, a23], [0, 0, 1]] · [x; y; 1](2.45)

给矩阵 A 赋不同的值，就能实现五种基本变换（都是 3×3 齐次坐标形式）：

变换矩阵说明
平移[[1,0,tx],[0,1,ty],[0,0,1]]右下角一列放位移量
缩放[[cx,0,0],[0,cy,0],[0,0,1]]对角线放缩放因子
旋转[[cosθ,−sinθ,0],[sinθ,cosθ,0],[0,0,1]]绕原点按矩阵正方向转 θ
镜像如 [[−1,0,0],[0,1,0],[0,0,1]]沿轴翻转
剪切（错切）[[1,sν,0],[0,1,0],[0,0,1]]让图形“歪”掉
易错矩阵乘法不满足交换律，顺序至关重要！“先缩放后平移”与“先平移后缩放”结果完全不同（前者平移量不会被缩放，后者会被缩放）。复合变换写在最左边的最后执行。
另外：直接按公式算出来的坐标是小数，必须再做一次插值（双线性/双三次）才能得到最终图像——这就是作业 2-36 的完整答案结构。

03灰度变换与空间滤波INTENSITY TRANSFORMS & SPATIAL FILTERING

本章是核心章节：直方图均衡是重点计算，卷积/相关与平滑、锐化也都是重点。先吃透例题，再练对应题库。

3.1 空间域的两类处理★★

g(x, y) = T[f(x, y)](3.1)

T 是作用在点 (x,y) 邻域上的算子。邻域大小为 1×1 时，s = T(r)，叫灰度变换（只跟这一个像素的值有关）；邻域大于 1×1 时，叫空间滤波（跟周围一圈像素有关）。这是全章的“总开关”。

3.2 四种基本灰度变换★★★

变换公式曲线形状 / 效果典型应用
图像反转s = L − 1 − r过 (0,L−1)、(L−1,0) 的直线，斜率为 −1增强暗背景中的白色/灰色细节（如乳腺 X 光片）；也用于求补
对数变换s = c·log(1 + r)先陡后平：扩展低灰度（暗部）、压缩高灰度（亮部）动态范围极大时（傅里叶频谱显示）；低灰度细节增强
幂律（伽马）s = c·rγγ<1 曲线在上方 → 整体提亮；γ>1 → 整体压暗；γ=1 恒等显示器/相机 gamma 校正；MRI、航拍图整体明暗调整
分段线性分段定义可任意设计：对比度拉伸、灰度级切分、比特面切分对比度拉伸（低对比度图 → 拉开）、灰度切分（突出某灰度段）
关键区别对数变换只“抬暗压亮”，改变的是局部的相对对比度；伽马变换是整体提亮或压暗，改变的是整体亮度与灰度分布，且可以通过 γ 连续调节强弱。考试若问“两者区别”，就答这两句。

分段线性之比特面切分（Bit-Plane Slicing）

8 比特图像每个像素有 8 个二进制位，把同一位的所有像素抽出来，就得到 8 个“比特面”。例如灰度 106 = 01101010₂，则第 7、6、4、2 位面上该点为 1（显示时赋 255），其余位面为 0。高位面（第 8、7 位）承载大部分视觉信息，只用高 2 位重构就能大致看出原图；低位面基本是噪声。

3.3 直方图：图像灰度的“人口普查”★★★

定义：灰度级的函数，表示图像中每一级灰度与该灰度出现的频率之间的统计关系。设灰度级 rk，k = 0,1,…,L−1：

非归一化：h(rk) = nk　　（nk = 灰度为 rk 的像素个数）(3.6)
归一化：p(rk) = nk / (M·N)，且 Σ p(rk) = 1(3.7)

归一化直方图可以理解成灰度取值的概率分布——这一点是后面所有推导的基础。

直方图形态图像状况说明
集中在低灰度整体偏暗像素挤在左侧
集中在高灰度整体偏亮像素挤在右侧
集中在中间窄区间低对比度灰度跨度小，看起来“灰蒙蒙”
均匀铺满整个范围高对比度理想状态，细节最丰富
易错一幅图像有唯一的直方图，但一个直方图可以对应多幅不同的图像（因为直方图丢掉了位置信息）。这是判断题的常客。
另外：直方图处理只改变灰度值，不改变像素位置。

3.4 直方图均衡化（重点计算题）★★★

原理：一句话 + 一个直觉

直方图均衡就是找一个变换 s = T(r)，把原来“挤在一起”的灰度拉开摊平，使输出图像的直方图近似均匀分布，从而提高对比度。

直觉煎饼果子下面的面糊堆在中间——用刮板把它摊平，同样的面糊铺满整个锅。面糊总量（像素总数）不变，只是“摊开了”。权重高的灰度级被分割、拉伸、扩展；权重低的被合并、压缩。

数学上要求 T 在 0 ≤ r ≤ L−1 上严格单调递增（保证不出现灰度反转，且逆变换唯一）。由概率守恒：

ps(s) = pr(r)·|dr/ds|，要求 ps(s) = 1/(L−1)(3.10 / 3.13)

积分并取 s = T(r)，得到最重要的那个式子：

s = T(r) = (L − 1) · ∫0r pr(w) dw　（连续形式）(3.11)
sk = (L − 1) · Σj=0k pr(rj)　（离散形式，就是累积求和）(3.15)

说白了：把归一化直方图从 0 开始逐级累加（CDF），再乘以 L−1，然后按题目约定取整。就这么简单。

3.5 直方图匹配（规定化）★★

均衡化是“自动摊平”，但结果不可控；匹配是“按指定的形状摊”——先让原图均衡化，再让它去匹配目标直方图的均衡化结果，最后反变换回来。

z = G−1(s) = G−1[T(r)](3.19)
① 对输入图均衡化 → sk→② 对规定直方图算 G(zq) 并存表→③ 对每个 sk 找最接近的 G(zq)
→④ 建立 r→z 直接映射
对比项直方图均衡直方图匹配

结果总得到“全图均衡”的结果可增强特定灰度范围的结果

局部直方图处理：只在每个像素的小邻域（如 3×3）内做均衡，能把全局均衡“看不见”的局部细节挖出来，代价是计算量大、可能放大噪声。

3.6 相关与卷积：空域滤波的两块基石★★★

线性空间滤波 = 核（kernel / 模板）系数与核覆盖区域像素的乘积之和：

相关：w ☆ f (x,y) = Σs=−aa Σt=−bb w(s,t) · f(x+s, y+t)(3.34)
卷积：w ★ f (x,y) = Σs=−aa Σt=−bb w(s,t) · f(x−s, y−t)(3.35)
唯一区别卷积要把核先旋转 180°（上下翻、左右翻），相关不用。所以：卷积 = 把核翻转后再做相关。
若核关于中心对称（如盒式核、高斯核、拉普拉斯核），翻转后不变，两者结果相同——这是判断题最爱考的一句。
例一维信号 f = [2, 4, 6, 8, 10]，核 w = [1, 0, −1]。求中心点（对应 f 的第 3 个值 6）处的相关值与卷积值。
相关：g = 1×f(2) + 0×f(3) + (−1)×f(4) = 1×4 + 0 + (−1)×8 = −4。
卷积：先把 w 翻转为 [−1, 0, 1]，再算 g = (−1)×4 + 0×6 + 1×8 = +4。
结论：核不对称时，相关和卷积结果不同（这里正好差一个负号）；卷积的“翻转”就是差别的全部来源。
例用 Sobel 竖直方向核 w = [[−1,−2,−1],[0,0,0],[1,2,1]] 对下图中心点做相关运算。
图像（5×5，上两行灰度 20，下三行灰度 60，即中间有一条水平边缘）：取中心点所在 3×3 窗口 = [[20,20,20],[60,60,60],[60,60,60]]。
g = (−1)(20) + (−2)(20) + (−1)(20) + 0 + (1)(60) + (2)(60) + (1)(60) = −80 + 240 = 160。
说明：响应值大 ⇒ 此处有水平边缘。梯度幅值 M ≈ |gx| + |gy|，本题只有 y 方向响应，故 M ≈ 160。

边界延拓（Padding）★★

为什么需要：核放在图像最边上时，有一半会“悬空”，没有像素可乘。解决办法是在图像外面补一圈值。四种方式：

类型补什么特点 / 适用
定值（补零）常数，通常 0最简单；会在边界产生暗边/伪边缘
对称（镜像）以边界为轴镜像复制边界过渡自然，去噪常用
复制（边界克隆）复制最边上一行/列的值保持局部均值，不引入突变
循环（周期）从对面绕回来与 DFT 的隐含周期性一致；但频域滤波前为防混叠通常用补零

补零的另一个重要作用：频域滤波前必须补零，否则 DFT 的隐含周期性会造成“混叠”（详见 4.6）。

3.7 平滑（低通）滤波器★★★

滤波器核的形式效果特点适用场景
盒式（均值）全 1/(mn)，如 3×3 全 1/9简单快速；沿垂直/水平方向产生线性模糊，边缘过渡生硬，有方块感粗略平滑；阈值化、分割前的预处理
高斯（GLPF）w(s,t) = K·e−(s²+t²)/2σ²唯一可分离的圆对称核（可拆成两个一维核，速度快）；边缘过渡更平滑、无方向偏好精细细节或强几何分量图像的平滑；去高斯噪声
中值取邻域排序后的中间值非线性；保边（阶跃/脉冲不会被抹平）；对椒盐噪声效果极好椒盐噪声；去除孤立亮点/暗点

易错① 盒式核 vs 高斯核：盒式是等权平均，易产生较生硬的模糊；高斯是圆对称、可分离的加权核，过渡通常更自然。
② 中值滤波首选椒盐噪声；对高斯噪声通常优先考虑均值/高斯等线性滤波。
③ 平滑可能模糊边缘，核越大、平滑越强，细节损失风险通常越大。

3.8 锐化（高通）滤波器★★★

先分清一阶导与二阶导

导数离散定义对边缘的响应（必背）
一阶∂f/∂x = f(x+1) − f(x)在边缘处产生一个宽峰（较粗）

04频率域滤波FILTERING IN THE FREQUENCY DOMAIN

这一章概念多、公式吓人，但复习时先抓住三件事：DFT 四个参数是什么、滤波六步是什么、三种低通/高通滤波器有什么区别。把这三件事掌握，可覆盖本章大部分基础考点。

4.1 为什么要换到频率域★★

傅里叶分析把图像表示为不同空间频率、方向、幅度和相位的二维复指数（正弦/余弦）成分之和——这就是二维傅里叶变换的物理含义。频谱就是“频率的分布曲线”。

直觉图像里缓慢变化的灰度（大片天空、墙面）对应低频；急剧变化的灰度（边缘、细节、噪声）对应高频。所以：低通滤波 = 模糊/平滑；高通滤波 = 锐化/边缘提取。

二维离散傅里叶变换（DFT）与逆变换（IDFT）：

F(u,v) = Σx=0M−1 Σy=0N−1 f(x,y)·e−j2π(ux/M + vy/N)(4.67)
f(x,y) = (1/MN) Σu Σv F(u,v)·ej2π(ux/M + vy/N)(4.68)

4.2 四个参数：频率、幅度、相位、方向★★★

F(u,v) 是复数，可写成 F(u,v) = R(u,v) + jI(u,v) = |F(u,v)|·ejφ(u,v)，于是有四个量：

参数怎么算物理意义（考填空）
频率√(u² + v²)，即中心化频率坐标点 (u,v) 到频谱中心的距离灰度变化的快慢。距中心越远，频率越高
幅度|F(u,v)| = √(R² + I²)该频率成分的强弱；频谱图显示的通常就是它（取对数后）
相位φ(u,v) = atan2(I(u,v), R(u,v))（注意象限）该频率成分的位置/偏移；携带结构信息
方向二维点 (u,v) 构成的向量方向该频率成分对应的条纹走向

三条必背性质

  • 平移性：图像在空间平移，频谱幅度不变，只改变相位（乘一个 e−j2π(x₀u/M+y₀v/N) 因子）。所以在空域移动物体，频谱图看起来一模一样。
  • 旋转性：图像在空间旋转 θ，频谱也旋转 θ。所以旋转图像时，其频谱也会随整体坐标系同向旋转；对于理想直线，过中心的谱线方向则与原直线垂直。
  • 周期性：DFT 的空域与频域都是无限周期延拓的，周期为 M、N。这是“用 DFT 实现线性卷积时需要考虑补零”的根本原因。

4.3 频率域滤波的六个步骤（必背）★★★

① 乘 (−1)x+y 中心化→② 计算 DFT 得 F(u,v)→③ 乘以滤波器 H(u,v)→④ 计算 IDFT
→⑤ 取实部→⑥ 再乘 (−1)x+y 取消乘数
g(x,y) = Real{ 𝓘−1[ H(u,v)·F(u,v) ] }(4.104)

为什么第 ⑤ 步要“取实部”？因为 IDFT 的结果理论上应是实数，但由于浮点误差会带一个极小的虚部，必须丢弃。为什么第 ⑥ 步要再乘一次？ 因为第 ① 步乘了 (−1)x+y，不乘回来会留下棋盘式正负交替，而不是还原原图。

4.4 低通滤波器：模糊与平滑★★★

D(u,v) 是频率平面上点 (u,v) 到中心 (P/2, Q/2) 的距离，D₀ 是截止频率。

滤波器传递函数特点（考试重点）
理想低通 ILPFH = 1，D(u,v) ≤ D₀；H = 0，D > D₀“一刀切”，会产生明显振铃效应（因为其空域核是 sinc 函数形状，外侧小波瓣造成振铃）
高斯低通 GLPFH = e−D²(u,v) / 2D₀²曲线平滑过渡，教材意义下无振铃；过渡柔和，但过强的低通仍会丢失细节
巴特沃斯 BLPFH = 1 / [1 + (D/D₀)2n]介于两者之间；阶数 n 越大越接近理想（振铃越明显），n 越小越接近高斯
振铃从哪来频域里一个“陡峭的矩形”对应空域里一个“无限振动的 sinc”。用 sinc 去卷积图像，边缘两侧就会出现一圈圈明暗波纹，这就是振铃。结论：频域截止越“硬”，空域振铃越明显。

低通的应用：磨皮去皱纹、消除卫星图像的扫描线、修复断裂的低分辨率文本（让断裂处“连上”）、平滑噪声。

4.5 高通滤波器：锐化与边缘★★★

HHP(u,v) = 1 − HLP(u,v)(4.119)
滤波器传递函数特点
理想高通 IHPFH = 0（D ≤ D₀）；H = 1（D > D₀）边缘最锐利，但振铃最严重（空域核有过冲）
高斯高通 GHPFH = 1 − e−D²/2D₀²无振铃，边缘平滑但稍“糊”
巴特沃斯高通 BHPFH = 1 / [1 + (D₀/D)2n]折中，n 控制锐利程度
常考对比三种滤波器滤波后的图像，理想的最“锐”但振铃最明显，高斯的最“软”但最干净，巴特沃斯居中。若题目问“为什么实际中更常用高斯/巴特沃斯”，答：为了抑制振铃。高通的应用：指纹增强、电路板缺陷、锐化。

4.6 选择性滤波：带阻、带通、陷波★★

类型作用典型场景
带阻（Bandreject）只压制以 C₀ 为中心、宽 W 的一圈频率压制某个频率范围的噪声
带通（Bandpass）1 − 带阻；只保留某个频率环提取特定尺度的纹理
陷波（Notch）在频谱上“挖掉”若干点（成对出现，因为频谱共轭对称）消除周期噪声：莫尔条纹、扫描线、电气/机电干扰、土星环图像的周期干扰
为什么陷波能去周期噪声周期噪声在频谱上表现为一对（或多对）孤立的亮点（共轭冲激）。把这几个点挖掉，再反变换，噪声就消失了。这是“频域有针对性处理”的最典型例子——复习提纲也把陷波列为需要掌握的频域方法。

4.7 频域滤波的边界问题★★

因为 DFT 隐含周期性，“先低通滤波再反变换”等价于“在空域用周期延拓后的图像做卷积”。若图像左右/上下边界灰度差异大，周期延拓会在接缝处造出虚假的边缘，滤波后表现为边界处的亮暗带（混叠）。

解决办法：滤波前把图像补零（通常补到 2M×2N），在真实图像与它的周期副本之间插入一个“缓冲带”。作业 4-41 就是在问：只要补零的总量相同，无论补在下侧还是右侧，效果一样——因为周期延拓后形成的“棋盘格”完全一样。

本章必会

① 四个参数：频率=距离、幅度=强弱、相位=位置、方向=条纹走向；② 滤波六步（含两次乘 (−1)x+y 与取实部）；③ 低通三兄弟对比（振铃：理想>巴特沃斯>高斯）；④ 高通 = 1 − 低通；⑤ 陷波治周期噪声；⑥ 补零防混叠。

05图像复原IMAGE RESTORATION AND RECONSTRUCTION

这一章的核心是：不同的噪声，应优先考虑不同的滤波器。重点掌握噪声模型与典型滤波器的对应关系。

5.1 退化/复原模型★★

g(x,y) = h(x,y) ★ f(x,y) + η(x,y)　⟺　G(u,v) = H(u,v)F(u,v) + N(u,v)(5.1–5.2)

其中 h 是退化函数（如模糊核），η 是加性噪声。复原就是已知或估计出 h 和 η 之后，反过来求 f。图像增强是主观的、为了好看；图像复原是客观的、为了还原真实——这是两者最本质的区别（简答题常考）。

5.2 六种噪声模型★★★

噪声概率密度函数 p(z)产生原因形状 / 记忆点
高斯1/[√(2π)·σ]·e−(z−μ)²/2σ²电子电路、传感器热噪声、低照度钟形对称；最常用、数学最好处理
瑞利(2/b)(z−a)·e−(z−a)²/b，z ≥ a距离/深度成像、雷达单边、右偏，从 a 起跳
爱尔兰（伽马）[abzb−1/(b−1)!]·e−az，z ≥ 0激光成像比瑞利更“对称”一些，b 控制形状
指数a·e−az，z ≥ 0激光成像在 z=0 处最高，单调下降
均匀1/(b−a)，a ≤ z ≤ b量化噪声（理论上）矩形，两端突然截断
椒盐（脉冲）Ps（z = 255）；Pp（z = 0）；1−Ps−Pp（z = V）快速瞬态（开关错误、传感器坏点）只有两个极端值：亮白点=盐，黑点=胡椒
怎么记盐是白的（255），胡椒是黑的（0）。“椒盐”= 图像上撒了黑白芝麻。它的直方图在两端各有一个尖峰，中间是原图的分布。

噪声参数估计：取图像中一块“平坦”区域（灰度本应恒定），统计其均值与方差即可估计噪声参数——这就是“用小条带估计噪声”的方法。

5.3 只存在噪声时的空域复原：均值滤波器★★★

前提：只考虑加性噪声，g = f + η，不考虑模糊。此时复原就是“平滑”。Sxy 是以 (x,y) 为中心的 m×n 邻域。

滤波器公式适用噪声（必背）
算术平均(1/mn)·Σ g(r,c)高斯、均匀噪声；会模糊
几何均值[Π g(r,c)]1/mn高斯、均匀；平滑程度与算术平均相当，但丢失细节更少
谐波平均mn / Σ[1/g(r,c)]盐噪声和高斯噪声好；不能用于胡椒噪声（除以 0 会爆炸）
反谐波平均Σ gQ+1 / Σ gQQ > 0 治胡椒（黑点）；Q < 0 治盐（白点）；Q = 0 退化为算术平均；不能同时处理两者
易错反谐波滤波器的 Q 符号必须与噪声类型匹配：用错符号不但去不掉噪声，还会把噪声放大成大片黑斑/白斑。记住：Q>0 常用于抑制胡椒（暗点），Q<0 常用于抑制盐（亮点）；但混合噪声、窗口内有目标细节时不能机械套用。

5.4 统计排序滤波器★★★

滤波器公式适用场景
中值median{ g(r,c) }椒盐噪声的常用首选；保边；可反复使用逐步去噪
最大值max{ g(r,c) }去胡椒（暗点）噪声——因为取最大会把黑点“顶掉”
最小值min{ g(r,c) }去盐（亮点）噪声
中点[max + min] / 2适合随机分布噪声（如均匀、部分高斯噪声）；不宜用来记忆为椒盐首选
修正阿尔法均值(1/(mn−d))·Σ剩余 gR(r,c)总共删去 d 个排序后的极端值（高端 d/2 个、低端 d/2 个，d 取偶数）再平均；适合混合噪声

自适应滤波器：邻域大小或权重随局部统计量（均值、方差）变化。自适应中值滤波能在噪声密度很大（如 0.25）时仍然工作，而固定 7×7 中值滤波已经糊成一片。

5.5 频域方法：压制周期噪声★★

周期噪声在频谱上通常表现为孤立亮点或窄带峰，因此可用陷波、带阻直接压制；也可用带通先提取噪声再从原图减去。这是频域选择性滤波的应用。

一张“选滤波器”表（答题参考）

高斯噪声 → 算术平均 / 几何均值 / 高斯低通；均匀噪声 → 算术平均 / 中点；椒盐 → 中值（或最大值去胡椒、最小值去盐）；只有盐 → 谐波平均或反谐波 Q<0；只有胡椒 → 反谐波 Q>0；混合噪声 → 修正阿尔法均值；周期噪声 → 陷波/带阻。

06彩色图像处理COLOR IMAGE PROCESSING

这章概念密集，但主线很清楚：三个特性、三个模型、一张色度图、一个伪彩色。把“谁用于显示、谁用于打印、谁最符合人眼”这条线记住，这章的主线就抓住了。

6.1 彩色的三个物理特性★★★

特性英文定义通俗理解
亮度Intensity / Brightness体现无色的强度概念，即光的强弱把彩色照片转成黑白，剩下的那个“明暗”
色调Hue与主波长相关的属性，观察者感知的主要颜色“这是什么颜色”——红、绿、蓝
饱和度Saturation一种颜色中混入白光的量，与所加白光成反比“颜色有多纯”——掺的白光越多越淡

可见光波长约 400～700 nm。人眼视网膜上的锥状细胞是彩色传感器，约 600～700 万个，分三类：65% 对红光敏感、33% 对绿光敏感、仅 2% 对蓝光敏感（人眼对蓝色细节相对不敏感；JPEG 对色度通道下采样还利用了人眼对色度变化不及亮度敏感这一特性）。

6.2 色度与 CIE 色度图★★★

x = X/(X+Y+Z)，　y = Y/(X+Y+Z)，　z = Z/(X+Y+Z) = 1 − x − y(6.1–6.3)

X、Y、Z 是三色值（形成某颜色所需的红、绿、蓝数量），x、y、z 是三色值系数（色度坐标）。因为 x+y+z=1，所以只要 x、y 两个数就能在色度图上定位一种颜色。

色度图的四个常见用法（建议掌握）

  • 定颜色：给出 (x, y)，在图上找到对应点，就知道是什么颜色。
  • 判断饱和度：边界上的点是全饱和（纯）色，越往中心（白光点）越不饱和。
  • 颜色混合与色域：两点连线上是其加色混合结果；三点围成的三角形表示相应设备色域。求补色时应沿等能白点作直线并与光谱轨迹相交，注意并非每个点都有光谱轨迹上的补色。
  • 比较色域（Color Gamut）：三个原色点在图上围成的三角形面积越大，该色彩空间能表示的颜色越多（应结合具体原色与白点比较，不能笼统认为所有色域严格嵌套）。

6.3 三种彩色模型：谁用于什么★★★

模型分量原理典型设备/场合关键点
RGB红、绿、蓝加色（光叠加）显示器、摄像机、扫描仪面向硬件；笛卡尔坐标，三原色在立方体三个角；三通道各 8 bit → 24 bit 像素深度
CMY青、品红、黄减色（颜料吸收）彩色打印机、复印机是光的二次色、颜料的原色
CMYK青、品红、黄、黑加第 4 色黑印刷因为 CMY 等量混合得到的黑不纯（发棕），才加 K
HSI色调、饱和度、亮度符合人眼描述方式图像处理算法（分割、增强）I 与彩色信息无关，H、S 与人感受颜色的方式紧密相连
CMY：　[C; M; Y] = [1; 1; 1] − [R; G; B]　　（RGB 也可由 CMY 直接反算）(6.5)
CMYK：K = min(C, M, Y)，　C = (C − K)/(1 − K)　（M、Y 同理）(6.6, 6.10–6.12)
HSI 的核心价值在 HSI 里做增强，只改 I 分量就能调亮度，而保持 H、S 不变；只改 H 就能调整色调而不直接改 I。RGB 的通道操作通常会同时改变亮度和颜色。所以“彩色图像直方图均衡”应当只在 I 分量上做（若分别对 R、G、B 做均衡，会产生奇怪的偏色）。

RGB → HSI 的关键式（只需记住 I 的那个）：I = (R+G+B)/3；S = 1 − 3·min(R,G,B)/(R+G+B)；H 由 θ = arccos{…} 得到，若 B > G 则 H = 360° − θ。反过来 HSI→RGB 要按 H 落在 [0°,120°)、[120°,240°)、[240°,360°) 三段分别计算。

6.4 伪彩色处理★★★

定义伪彩色（假彩色）图像处理：基于一种指定规则，对灰度值赋以颜色的处理——不同灰度区域赋予不同颜色。输入是灰度图，输出是彩色图，颜色是“人为指定”的，不是真实的，故名“伪”。

为什么有效：人眼对颜色的区分能力通常强于对灰度的区分能力（课件概括为几十级灰度与几千种颜色）。伪彩色有助于呈现原本不易分辨的灰度差异，但不会增加原始测量信息。

方法原理例子
灰度分层（彩色编码）用平行于坐标面的平面“切”灰度曲面，每个灰度区间赋一种颜色：若 f(x,y) ∈ Ik，则令 f = ck8 色分层显示甲状腺模型；焊点 X 光图
灰度到彩色变换对每个像素灰度做三个独立的变换，分别送 R、G、B 通道，合成彩色图行李 X 光安检：橙色=轻元素（原子序数<10，食品纸张布料）、绿色=中元素（10～18，爆炸物）、蓝色=重金属（>18，铜铁锌）

灰度到彩色变换是灰度分层的推广（分层是它的特例，变换函数取阶梯状）。多光谱图像的彩色编码也属于这一类：把不同波段的灰度图分别送进 R、G、B。

6.5 彩色图像处理的两条路线★★

① 分通道处理：把彩色图看成三幅分量图，各自处理再合成；② 向量处理：把每个像素看成三维向量，直接对向量运算。

两者等价的条件（简答常考）只有当 ① 该操作对向量和标量都适用，且 ② 对每个分量的操作与其他分量无关（独立） 时，两条路线结果才相同。
所以：平滑、锐化可以在 RGB 中分通道做（线性、各分量独立）；但彩色边缘检测不能简单合并三个标量梯度——可能漏掉“色调改变而各通道标量梯度相互抵消”的彩色边缘。
操作正确做法说明
平滑RGB 各通道分别均值滤波 ＝ RGB 向量平均；也可只对 HSI 的 I 分量平滑RGB 两种写法等价；与 HSI 只处理 I 并不严格等价，课件展示了二者差值
锐化RGB 各通道分别求拉普拉斯再合成；也可只对 HSI 的 I 分量做RGB 分通道与向量拉普拉斯等价；与 HSI 只处理 I 不严格等价
直方图均衡只在 I 分量上做分别对 RGB 做会破坏彩色平衡
边缘检测用彩色向量梯度（Di Zenzo）：算 gxx、gyy、gxy 三个点积，再求最大变化率方向 θ = ½arctan[2gxy/(gxx−gyy)]标量梯度公式不能直接套到向量上

6.6 彩色图像中的噪声（特点必背）★★★

  • 各通道噪声特性相同，但影响程度不同。因为每个通道的相对照射强度不同：CCD 的红色滤镜会减少红光照射强度，低照度下红通道噪声更明显；而蓝色通道噪声通常最明显（人眼对蓝最不敏感，且蓝光能量低）。
  • 某一通道的噪声可能通过 RGB→HSI 变换耦合到其他分量。课件示例中，绿色通道椒盐噪声影响了 H、S、I；实际哪个分量受影响取决于像素颜色与噪声位置，不应理解为任何单通道噪声必然同时污染全部三个分量。
  • 彩色图像中的颗粒噪声不如灰度图像显眼。同样的噪声幅度，人眼在彩色图里更不容易察觉（彩色信息“掩盖”了亮度噪声）。

6.7 彩色分割与彩色压缩（了解）★

HSI 分割：通常利用 S 找出彩色区域，再结合 H 区分色调，I 用于辅助亮度分割；适合“颜色单一、亮度变化”的目标（如木卫一）。
RGB 分割：给定感兴趣颜色的样本集，算平均色 a，再判断像素 z 与 a 的距离是否小于阈值。三种度量：欧氏距离（球体）、马氏距离（椭球体，考虑协方差）、边界盒（避免开方，最快）。
JPEG 压缩：① 转到 YCrCb，利用人眼对色度不敏感对 Cr、Cb 下采样；② 二维 DCT 变换，舍弃高频；③ 用量化表量化；④ Huffman 编码去冗余。所以 JPG 是有损压缩，PNG 是无损，BMP 基本不压缩。

本章必会

① 三特性定义（尤其饱和度与白光成反比）；② 色度坐标 x+y+z=1、边界=全饱和；③ RGB 用于显示/CMY(K) 用于打印/HSI 最符合人眼，且 HSI 只改 I 可保持 H、S 不变；④ 伪彩色定义 + 灰度分层 + 灰度到彩色变换；⑤ 彩色噪声三条特点（尤其“单通道噪声可能耦合到其他 HSI 分量”）。

9.1 结构元：形态学的“印章”★★★

定义结构元（Structuring Element, SE）是一个小集合（小矩阵），用来探测图像中感兴趣的形状。它有两个要素：成员（涂色的方块，值为 1）和原点（用黑点标出；若 SE 对称且未标原点，则默认原点在对称中心）。不关心的位置记为 ×（don't care）。

两个基本运算：反射 B̂ = {w | w = −b, b ∈ B}，即把 SE 绕原点旋转 180°；平移 (B)z = {c | c = b + z, b ∈ B}，即把原点移到 z。

用法约定把待处理集合 A 也用背景元素“补成一个矩形”，并且当 SE 的原点落在 A 的边界上时，背景边界要大到足以容纳整个 SE。考试给图时通常已经按这个规则画好了。

9.2 腐蚀：能不能整个塞进去★★★

A ⊖ B = { z | (B)z ⊆ A }　=　{ z | (B)z ∩ Ac = ∅ }(9.3–9.4)

怎么理解：把结构元的原点依次放到图像中每个位置 z，若此时 SE 的所有成员都落在前景内（完全被 A 包住，一个都不碰到背景），则 z 保留，否则 z 被删掉。

效果收缩、细化。它会抹掉比结构元小的细节、断开细的连接、缩小物体。用途：去除小物体、分离粘连物体（计数前的关键步骤）、保留最大的区域、求边界。
  • 用原点居中的 3×3 方形 SE腐蚀一次 ≈ 把物体四周各削掉 1 个像素（仅限该对称结构元）。
  • 用特定形状 SE腐蚀，可保留能容纳该结构元的部分，结果取决于目标形状、SE 与原点。

9.3 膨胀：碰到没有★★★

A ⊕ B = { z | (B̂)z ∩ A ≠ ∅ }(9.5)

怎么理解：把 SE 先反射（对称时反射不变），再平移；只要它与 A 有任何一个像素重叠，该位置 z 就保留。

效果增长、粗化。它会扩展边界、填补小孔洞、弥合细小裂缝、连接断裂的字符。用途：修复断裂文字、连接碎片、填充孔洞、边界检测（膨胀图 − 原图 = 边界）。

9.4 开运算与闭运算★★★

开运算：A ∘ B = (A ⊖ B) ⊕ B　　（先腐蚀，再膨胀）(9.10)
闭运算：A · B = (A ⊕ B) ⊖ B　　（先膨胀，再腐蚀）(9.11)
运算效果（必背）典型应用
开平滑轮廓、断开窄狭颈、消除细小突出物；外角变圆、内角不受影响；删除小物体去掉噪声小点（前置滤波）、分离物体、统计颗粒
闭弥合窄间断和细长沟壑、消除小孔洞、填补轮廓断裂；内角变圆、外角不受影响填充孔洞、连接断裂线条、指纹修复
几何解释把 SE 想象成一个球：开运算是球在 A 的边界内侧滚动，球能到达的边界最远点构成新边界（所以凸出的尖角被“滚掉”）；闭运算是球在 A 的边界外侧滚动，形成的内包络就是结果（所以凹陷被“填平”）。

三条性质（常考判断）：① A∘B 是 A 的子集（开运算只会变小）；A 是 A·B 的子集（闭运算只会变大）；② 单调性：C ⊆ D ⟹ C∘B ⊆ D∘B；③ 幂等性：(A∘B)∘B = A∘B，即重复做开运算没有额外效果（闭运算同理）。

9.5 击中—击不中变换（HMT）★★

A ⊛ B = (A ⊖ B1) ∩ (Ac ⊖ B2)，　B = (B1, B2)(9.16)

B1 是“应命中”部分（对应前景），B2 是“应击不中”部分（对应背景）；两者同时满足才输出。本质是完全的模板匹配：在图中找特定形状并输出其原点，是细化、粗化、凸壳、骨架的共同基础。

10图像分割IMAGE SEGMENTATION

本章内容最多、综合题常用。提纲点名了五块：Hough、Canny、超像素/SLIC、k-Means、阈值处理（含 Otsu）、DBSCAN，而且明确提示“可能在大题中结合使用”。

10.1 分割是什么，好的分割要满足什么★★

定义图像分割：把图像细分为构成它的子区域或物体。细分的程度取决于要解决的问题；当感兴趣的物体或区域已经检测出来，就停止分割。

把图像区域 R 分成 n 个非空子区域 R1…Rn，必须同时满足 5 个条件（填空/简答常考）：

① ∪Ri = R（全覆盖）；② Ri ∩ Rj = ∅（互不重叠）；③ 每个 Ri 连通
④ 每个 Ri 满足均匀性测度 Q(Ri)=TRUE（区域内相似）；⑤ 任意相邻子区域的并 Q(Ri∪Rj)=FALSE（区域间不同）

两大类方法：基于灰度不连续性（找边缘：点、线、边缘检测）与基于灰度相似性（找区域：阈值、区域生长、聚类/超像素、分水岭、图割）。

10.2 点、线检测★★

孤立点检测用拉普拉斯（二阶导）：模板响应绝对值超过阈值就判为点。

线检测：二阶导对细线响应更强，但会产生双线效应（3×3 核放在宽 5 像素的恒灰度线上响应为 0，结果在线两侧各出现一条）。检测特定方向用四个方向的模板，系数之和都为 0，保证恒定灰度区响应为 0。

10.3 边缘检测与 Canny（重点）★★★

边缘模型与三个步骤

边缘按灰度剖面分三类：台阶（理想突变）、斜坡（实际，有宽度）、屋顶（细线状，先升后降）。

为什么先平滑导数对噪声极敏感，微弱噪声就能淹没一阶/二阶导数图。故边缘检测三步为：① 平滑降噪 → ② 检测边缘点（找候选）→ ③ 边缘定位（筛出真实边缘）。

基本梯度算子：Roberts（2×2）、Prewitt（3×3，系数全 1）、Sobel（3×3，中心加权 2，抗噪更好）。

Canny 边缘检测器：三个目标 + 四个步骤

三个设计目标含义
① 低错误率既不漏掉真边缘，也不把非边缘判成边缘
② 定位准确检出的边缘要落在真正的边界上
③ 单一响应一条边缘尽量只产生一条响应，避免粗重边缘与重复响应
① 高斯滤波平滑→② 计算梯度幅值与方向→③ 非极大值抑制 NMS→④ 双阈值处理与边缘连接
G(x,y) = e−(x²+y²)/2σ²；　fs = G ★ f
Ms(x,y) = |∇fs| = √(gx² + gy²)，　α(x,y) = arctan(gy/gx)(10.35–10.38)

改进点一：非极大值抑制（NMS）——把边缘“瘦身”

高斯平滑会把边缘变宽，梯度幅值图上一条边会形成一条“山脊”。NMS 的目的就是只保留山脊的最高点，把边缘细化到 1 个像素。

  1. 把梯度方向量化为四类：水平（0°）、垂直（90°）、+45°、−45°。
  2. 对每个像素，沿其梯度方向（即边缘法线方向）取前后两个相邻像素的梯度幅值。
  3. 若当前像素的幅值同时大于这两个邻居，则保留（它就是局部极大值）；否则置 0（抑制）。
一句话沿着梯度方向看两边，我不是最大的就不要我。遍历完，每条边缘只剩一条“山脊线”，宽度约为 1 像素。

改进点二：双阈值处理——把边缘“连起来”

设高阈值 TH、低阈值 TL，一般 TH : TL = 2:1 ～ 3:1。对 NMS 后的图像 gN：

条件处理
gN(x,y) > TH直接判为强边缘（一定保留）
gN(x,y) < TL直接排除（一定不是边缘）
TL ≤ gN ≤ TH弱边缘：只有与已确定的强边缘像素邻接时才判为边缘，否则丢弃
双阈值解决了什么单阈值永远两难：阈值高 → 边缘断裂、不连续；阈值低 → 出现大量伪边缘。双阈值用“高阈值保证可靠、低阈值保证连续”：高阈值找出确定是边缘的骨架，低阈值把与骨架相连的“尾巴”补上。这就是 Canny 相比普通梯度阈值法的本质改进。

代价：相较简单梯度阈值法，步骤更多、参数更多，计算与实现成本更高（课件尤其指出早期计算机上的速度问题）。所以当更看重速度时用简单阈值梯度法，更看重边缘质量时用 Canny。最后通常还要做一次边缘细化，得到真正的 1 像素宽边缘。

10.4 Hough 变换（重点计算/简答）★★★

要解决什么问题

边缘检测得到的只是零散、常断裂的点。要把它们连成直线/圆，笨办法是枚举所有点对：n 个点约 n² 条直线，再逐点比较共 ~n³ 次运算——太慢。Hough 变换换了思路。

核心思想：点—线对偶

思想图像空间里的一个点 → 参数空间里的一条曲线（斜截式下为直线，法线式下为正弦曲线）；共线的点 → 曲线交于同一点。于是“找共线点”变成了“找累加器里的峰值”——一个投票问题。

先用斜率截距式 y = ax + b：点 (xi, yi) 对应参数平面上的一条直线 b = −xia + yi。但直线接近垂直时 a → ∞，参数平面上的直线变成平行线，没有交点。于是改用法线式（极坐标）：

ρ = x·cosθ + y·sinθ　（θ ∈ [0°, 180°)，ρ 为原点到直线的垂距）(10.44)

这样一个点 (x,y) 在 ρ-θ 平面上对应一条正弦曲线；同一条直线上的多个点，其曲线会交于同一点 (ρ, θ)。

例把直线 y = −2x + 1 写成法线式，求 θ 与 ρ。（作业 10-25）
由 y = ax+b 得 ax − y + b = 0。取 θ ∈ [0°,180°)、ρ ≥ 0，则单位法向量为
n = (−a, 1)/√(a²+1) = (cosθ, sinθ)，ρ = b/√(a²+1)。
代入 a = −2、b = 1：√5 ≈ 2.236，cosθ = 2/√5 ≈ 0.894，sinθ = 1/√5 ≈ 0.447，ρ = 1/√5 ≈ 0.447。
所以 θ ≈ 26.565°，ρ ≈ 0.447，即 x cos26.565° + y sin26.565° = 0.447。
验算：线上取 (0,1)，代入 0×0.894 + 1×0.447 = 0.447 ✓。若采用其他 θ/ρ 范围，可用 (ρ,θ) 与 (−ρ,θ+180°) 等价转换。
例点 (0,0) 在 ρ-θ 平面上的轨迹是什么？（作业 10-26）
代入 ρ = 0·cosθ + 0·sinθ = 0，对任意 θ 都成立 → 轨迹是 ρ = 0 的一条水平直线。只有原点会产生这个结果：任何非原点 (x,y) 的 ρ 会随 θ 变化，不可能恒为 0。

算法步骤（背这四步）

① 得到二值边缘图（推荐 Canny）→② 把 ρ-θ 平面划成累加单元并清零→③ 对每个前景点，遍历所有 θ 求 ρ，对应单元 +1→④ 找累加值最大的单元，其 (ρ,θ) 即直线参数

累加值 P 的含义：图像中有 P 个点位于直线 ρi = x cosθj + y sinθj 上。计算量与前景点数 n 呈线性关系（这是相对 n³ 的巨大改进）。同理可用于检测圆、椭圆（参数变成 3 个、4 个，累加器维数增加）。

10.5 阈值处理★★★

g(x,y) = 1（若 f(x,y) > T）；0（若 f(x,y) ≤ T）(10.46)

T 为常数 → 全局阈值（常用直方图法：取直方图双峰之间的谷点）；T 随位置变化 → 可变/自适应阈值。

Otsu（大津法）：让两类的“类间方差”最大

思想：把直方图分成 c₁、c₂ 两类，遍历所有可能的阈值 k，选那个使类间方差 σB² 最大的 k。类间方差越大，说明两类分得越开——这等价于“让类内方差最小”。

P1(k) = Σi=0..k pi，　P2(k) = 1 − P1(k)(10.49–10.50)
m1(k) = (1/P1)Σi=0..k i·pi，　m2(k) = (1/P2)Σi=k+1..L−1 i·pi(10.51–10.52)
mG = Σi=0..L−1 i·pi（全局均值）(10.54)
σB² = P1P2(m1 − m2)² = (mGP1 − m(k))² / [P1(1 − P1)]，　m(k)=Σi=0..k i·pi(10.60)
例8 级灰度（L=8），归一化直方图 p = [0.20, 0.30, 0.10, 0, 0.05, 0.10, 0.15, 0.10]。求 Otsu 阈值。
先算 mG = 0×.2+1×.3+2×.1+3×0+4×.05+5×.1+6×.15+7×.1 = 2.80。逐个 k 试：
k=0：P₁=.20, m₁=0；P₂=.80, m₂=3.50 → σB²=.20×.80×(0−3.50)² = 1.96
k=1：P₁=.50, m₁=0.60；P₂=.50, m₂=5.00 → σB²=.25×(0.60−5)² = 4.84
k=2：P₁=.60, m₁=0.833；P₂=.40, m₂=5.75 → σB²=.24×(0.833−5.75)² ≈ 5.80　← 最大
k=3：与 k=2 相同（因灰度为 3 的像素数为 0）≈ 5.80
k=4：P₁=.65, m₁=1.077；P₂=.35, m₂=6.00 → ≈ 5.51；k=5 ≈ 4.32；k=6 ≈ 1.96
本例 k=2 与 k=3 的 σB² 完全相同。若取 k*=2，则 c₁={0,1,2}、c₂={3,…,7}；按 g=1（f>T）规则取 T=2，即灰度 ≤2 为背景、≥3 为目标。若取 k*=3，则对应 T=3、≥4 为目标；两种最优分割因灰度 3 的概率为 0 而相同，但阈值写法不同。
Otsu 的适用条件① 近似双峰时通常效果较好；② 小目标或单峰直方图时可能分割不准；③ 全局 Otsu 更适合光照较均匀的图像，光照不均可先校正或改用局部阈值；④ 自动、快速，无需人工指定最终阈值。

可变（自适应）阈值

  • 基于局部性质：用每个像素邻域的均值 mxy 与标准差 σxy 共同构造局部阈值；具体公式与系数依算法及题目给定。
  • 基于移动平均：把图像按 Z 字形扫描成一维，用前 n 个点的滑动平均 mk 乘系数 b 作为该点阈值；两个参数是 n（参与平均的点数）和 b（阈值系数）。

10.6 k-Means 聚类★★★

聚类：按（欧氏）距离把样本划分为若干簇，使簇内相似、簇间不相似，属于无监督学习。k-Means 是“基于划分”的聚类，也是最常用的一种。

目标：最小化平方误差　E = Σi=1..k Σz∈Ci |z − mi|²，　质心 mi = (1/|Ci|)Σz∈Ci z(10.85)

直接求全局最优通常很困难，因此采用启发式迭代：

  1. 初始化：从样本中选 k 个点作为初始质心 m1…mk。
  2. 分配：对每个样本 zq，计算它到各质心的距离，把它归给最近的质心所在的簇。
  3. 更新：对每个簇重新计算质心（簇内所有点的均值）。
  4. 终止：若所有质心不再变化（或达到最大迭代次数），结束；否则回到第 2 步。

k 怎么定？（常考简答）

方法做法
试凑法取不同 k 分别跑，看效果（最朴素）
结合业务已知要分几类就设几类（如“水体/市区/植被”就是 3 类）
SSE（误差平方和）SSE 随 k 增大而减小；画 SSE–k 曲线，找拐点（肘部），越小越好但要注意过拟合
轮廓系数 ss = (b − a)/max(a,b) ∈ [−1, 1]。a = 样本与同簇其他点的平均距离，b = 与最近邻簇所有点的平均距离。s 越接近 1 越好，越接近 −1 越差
优点缺点
① 原理简单、实现容易；② 效果较优、收敛快；③ 可解释性强（簇/质心）；④ 只需调一个参数 k① k 不易把握；② 非凸或 elongated 簇的划分效果差（并非一定不收敛）；③ 各类数据不平衡（长尾/方差不同）时效果差；④ 只能得局部最优；⑤ 对噪声和异常点敏感

k-Means++：改进初始质心的选法——第一个质心随机选，之后每选一个新质心时，离已选质心越远的点被选中的概率越大。这样初始质心分散，收敛更快、结果更稳定。

10.7 超像素与 SLIC★★★

超像素由具有相似纹理、颜色、亮度等特征的相邻像素构成的、有一定视觉意义的不规则像素块。它把“像素级”降到“块级”，用几百到几千个超像素代替几十万个像素，大幅降低后续处理复杂度，通常作为分割算法的预处理步骤。

SLIC（Simple Linear Iterative Clustering，简单线性迭代聚类）：2010 年提出，把彩色图像转成 CIELAB 颜色空间 + XY 坐标的 5 维特征向量 [l, a, b, x, y]T，再对这个 5 维向量做局部 k-Means 聚类。

两个关键设计（这是它不同于普通 k-Means 的地方）

设计内容解决了什么
① 限制搜索范围每个聚类中心只在其 2S×2S 的邻域内搜索像素（S 为网格间隔）把 k-Means 的复杂度从“全图搜索”降为常数，对 N 个像素，典型实现约为 O(N)（迭代次数固定时）
② 5 维距离度量颜色距离 dc、空间距离 ds，再加权归一化同时考虑“颜色像不像”和“距离近不近”，生成的超像素更规整
S = √(N/k)　（N 为总像素数，k 为超像素个数）(10.86)
dc = √[(lj−li)² + (aj−ai)² + (bj−bi)²]，　ds = √[(xj−xi)² + (yj−yi)²]
D = √[(dc/m)² + (ds/S)²](10.87–10.89)
参数 m 怎么影响结果（重点）m 是紧凑度参数（控制颜色与空间距离的相对权重）（通常 1～40）。m 越大 → 空间距离的影响越显著 → 超像素形状越规整（越像方块）；m 越小 → 颜色相似度越重要 → 超像素越贴合图像边缘（颜色变化处）。

算法流程（五步）

① 在规则网格上按间隔 S 撒种子→② 把种子移到 3×3 邻域内梯度最低处→③ 每个中心在 2S×2S 内做 k-Means 分配
→④ 更新中心为簇内均值→⑤ 迭代至收敛（一般 10～20 次）

第 ② 步的作用：避免把超像素“种”在边缘上，也减少用噪声像素做种子。SLIC 默认主要设置超像素数 k，还可调节紧凑度参数 m。优点：① 超像素紧凑整齐；② 彩色/灰度图都能分；③ 参数极少；④ 速度快、轮廓保持好。

10.8 DBSCAN（基于密度的聚类）★★★

11.1 什么是特征★★

定义特征本质就是可以存储在计算机里的“数”，是从复杂数据中挑出的“关键信息”，用来排除干扰、区分不同目标。一般情况下数值越大，特征越强烈。

图像特征分四类：颜色（均值、直方图、颜色矩）、纹理（LBP、灰度共生矩阵）、形状（面积、周长、长宽比、矩）、空间关系（相邻、包含）。提取方法分传统（矩、边界、SIFT/HOG）与深度学习（CNN）。

11.2 拓扑描述子与欧拉数★★

拓扑描述子：在连续变形（拉伸、扭曲，但不撕裂、不粘连）下保持不变的性质，与距离、大小无关。

欧拉数 E = C − H　（C = 连通分量个数，H = 孔洞个数）
例字母 A：1 个连通分量、1 个孔洞 → E = 0；字母 B：1 个连通分量、2 个孔洞 → E = −1。
用途：快速筛掉形状不对的候选目标。

11.3 矩与 Hu 不变矩★★★

几何矩的物理意义

Mpq = Σx Σy xp yq f(x,y)　（p+q 为阶数）(11.34)
阶数矩物理意义
零阶M00图像灰度总和（“质量”）；二值图中前景为 1、背景为 0 时就是前景像素数（面积）
一阶M10、M01图像 x / y 方向的灰度中心（质心）
二阶M20、M02、M11惯性矩；确定目标的主轴、长轴、短轴（用来描述椭圆的朝向与长短）
三阶 / 四阶M30、M03、M21、M12 / M40 等三阶 = 投影的扭曲程度（偏斜）；四阶 = 峰度

问题：几何矩会随图像的平移、缩放、旋转、转置而变化，不能直接用来匹配。于是要“造”不变性：

质心：x̄ = M10/M00，　ȳ = M01/M00(11.36)
中心矩：μpq = ΣΣ (x − x̄)p (y − ȳ)q f(x,y)　⟹ 平移不变(11.35)
归一化中心矩：ηpq = μpq / μ00γ，　γ = (p+q)/2 + 1　⟹ 平移 + 缩放不变(11.37–11.38)

Hu 的七个不变矩

用二阶、三阶归一化中心矩组合成 7 个量，它们对平移、缩放、旋转都不变（前 6 个镜像不变，第 7 个镜像变号）：

φ1 = η20 + η02
φ2 = (η20 − η02)² + 4η11²
φ3 = (η30 − 3η12)² + (3η21 − η03)²
φ4 = (η30 + η12)² + (η21 + η03)²
φ5 = (η30−3η12)(η30+η12)[(η30+η12)² − 3(η21+η03)²] + (3η21−η03)(η21+η03)[3(η30+η12)² − (η21+η03)²]
φ6 = (η20−η02)[(η30+η12)² − (η21+η03)²] + 4η11(η30+η12)(η21+η03)
φ7 = (3η21−η03)(η30+η12)[(η30+η12)² − 3(η21+η03)²] − (η30−3η12)(η21+η03)[3(η30+η12)² − (η21+η03)²] (11.39–11.45)
抓重点这七个式子主要用于理解构成，通常无需手算。你应掌握：知道它们是由归一化中心矩组合而成、具有平移/缩放/旋转不变性、共 7 个，并且能说清用于匹配的流程。

Hu 不变矩做形状匹配的标准流程（大题直接套）

① 计算模板图像的 Hu 矩→② 目标图上连通区域分析，提取 ROI→③ 对每个 ROI 算 Hu 矩
→④ 算与模板的距离，最小者为匹配目标

距离度量（因为 Hu 矩数值跨几个数量级，先取对数或归一化再算）：常用 d = Σ|miA − miB| 或 d = Σ|1/miA − 1/miB|。工程上还会与颜色距离加权成“复合距离”，取最小者作为识别结果（课件无人机识别示例采用复合判据，具体公式以原图为准）。

11.4 PCA 主成分分析★★★

是什么PCA 是数据降维的经典统计手段：把高维数据投影到少数几个“最重要”的方向上，用低维表示原数据，并尽可能保留原始信息。

为什么要降维：高维空间数据极度分散（100 维、每维 10 值就有 10¹⁰⁰ 种组合），导致样本稀疏、计算爆炸、易过拟合；特征间还常有多重共线性（如“房价”与“面积”几乎完全正相关，有一列多余）。

五个步骤

  1. 中心化：每个特征减去其均值（把原点搬到数据重心）。
  2. 求协方差矩阵：C = (1/n)·Σ(xi−x̄)(xi−x̄)T，描述特征间的相关性。
  3. 特征值分解 / 奇异值分解：得到特征值 λ1 ≥ λ2 ≥ … 和对应特征向量。
  4. 取前 k 个最大特征值对应的特征向量作为新的坐标轴（主元 1、主元 2…）。
  5. 投影：把原数据乘上这组基，得到降维后的数据。
一句话直觉数据在二维平面上近似排成一条斜线，那“垂直于这条线”的那个坐标几乎没有信息。把坐标轴旋转到与数据分布最“长”的方向重合，然后丢掉最短的方向——这就是 PCA。丢掉的部分损失的信息最少。

作用：① 降维、减少计算量与存储；② 去相关（消除多重共线性）；③ 抑制噪声；④ 缓解过拟合；⑤ 便于可视化（降到 2～3 维画图）。

11.5 Harris 角点检测★★★

什么是角点用一个固定窗口在图像上沿任意方向滑动：怎么动灰度都不变 → 平坦区域；沿某一方向动不变、垂直方向动变化大 → 边缘；往哪个方向动变化都很大 → 角点。
E(u,v) = Σx,y w(x,y)·[I(x+u, y+v) − I(x,y)]²课件公式
泰勒展开 ⇒ E(u,v) ≈ [u, v]·M·[u, v]T，　M = Σ w(x,y)·[[Ix², IxIy], [IxIy, Iy²]]

M 的特征值 λ₁、λ₂ 描述了“两个方向上的变化速度”。为避免直接求特征值，Harris 定义响应：

R = det(M) − k·[trace(M)]²，　det(M) = λ1λ2，　trace(M) = λ1 + λ2
特征值情况R 的值判定
λ₁、λ₂ 都很小|R| 很小平坦区域
一个大、一个小R < 0（为负）边缘
两个都很大R 很大（正值）角点

系数 k 难以确定，Shi-Tomasi 改进为 R = min(λ₁, λ₂)。流程：① Sobel 求 Ix、Iy；② 构造 M；③ 算 R；④ 阈值 + 非极大值抑制。

优点缺点
① 从灰度变化定义角点，计算简单；② 课件意义下具旋转与光照变化的稳定性（固定阈值下并非对任意光照绝对不变）① 只适合简单背景/几何图形；② 缺少尺度不变性（图像放大缩小后，原来判定为角点的可能变成边缘）

应用：棋盘格标定（算单应矩阵、校正镜头畸变）、图像拼接、运动跟踪。

11.6 SIFT 尺度不变特征变换★★★

要解决什么同一物体在不同距离（尺度）、角度（旋转）、亮度下拍摄时，普通角点检测会失败。SIFT（1999，Lowe）提取的局部特征对旋转、尺度缩放、亮度变化保持不变，对视角变化、噪声也有一定稳定性——在图像内容仍可见且处于算法适用范围内时，特征具有较好的重复性。

三个关键概念（填空高频）

概念含义
尺度空间由不同高斯尺度 σ 与不同 Octave 下采样构成的一组图像，用于模拟不同观察尺度；下采样只是其中一步
高斯金字塔对尺度空间中每一层图像，在每个 Octave 内用不同 σ 的高斯核逐层模糊，Octave 之间再下采样；课件示例为同尺度多层图像
高斯差分金字塔（DOG）同一 Octave 内相邻两层高斯模糊图相减得到的新金字塔

四个步骤

① 找关键点（尺度空间极值）→② 定方向→③ 做描述（生成特征向量）→④ 比特征（匹配）
  1. 找关键点：在 DOG 金字塔中，每个像素与它同一层的 8 邻域 + 上下相邻两层的同位置 9×2 个点，共 26 个点比较，是极值就作为候选关键点。这样在金字塔覆盖的尺度范围内可重复检测相应极值——这是尺度不变性的主要来源。
  2. 定方向：在以关键点为中心的邻域内，统计所有像素的梯度方向直方图（把 360° 分成 8 个方向，箭头长度表示梯度大小），数量最多的方向即主方向。之后所有计算都以主方向为基准——“摆正”了，所以旋转后特征不变。
  3. 做描述：取关键点周围 16×16 像素，分成 4×4 个子区域，每个子区域统计 8 个方向的梯度直方图 → 4×4×8 = 128 维特征向量。n 个特征点就有 n×128 维描述向量。
  4. 比特征：两特征向量越相似（欧氏距离越小）越是同一点，据此完成匹配（拼接、识别）。
易错① 描述子为 128 维（SURF 常 64 维）；② 尺度不变性靠金字塔 + DOG 极值检测；③ 匹配还需几何一致性检验（如 RANSAC），不能只靠特征距离。

11.7 四件"特征工具"到底怎么选（易混点对比）★★

Hu 矩、PCA、Harris、SIFT 是本章四个最容易被问混的东西。它们的定位完全不同：Hu 描述"一个区域长什么样"，PCA 处理"数据维度太高"，Harris 找"角点在哪"，SIFT 找"关键点并给它一个身份指纹"。

工具解决什么问题不变性输出典型用途
Hu 不变矩区域形状的定量描述平移、缩放、旋转不变；第 7 个镜像变号7 维向量形状匹配、字符识别、无人机降落标志识别
PCA高维数据降维、去相关—（与几何变换无关）主元（投影后的低维坐标）特征压缩、去噪、可视化、缓解过拟合
Harris角点在哪（点特征）课件近似下具旋转/光照稳定性；无尺度不变角点坐标 + 响应 R棋盘格标定、运动跟踪、图像拼接的初匹配
SIFT跨尺度/视角的关键点 + 描述子旋转、尺度、亮度不变；对视角变化、噪声有一定稳定性关键点 + 128 维描述子图像拼接、目标识别、PCB 引脚匹配
一句话区分要"认形状"用 Hu；要"减维度"用 PCA；要"找点"用 Harris；要"在不同尺度下都能认出来"用 SIFT。大题里如果目标是"识别特定标志/字符"，标准组合是：分割 → 连通分量 → Hu 矩 → 最小距离/距离最小者；如果是"把两张图拼起来"，则是 SIFT 提特征 → 匹配 → 几何变换。

本章必会

① 欧拉数 E=C−H；② 矩：0 阶质量、1 阶质心、2 阶惯性矩/主轴；③ Hu：7 个、平移缩放旋转不变；④ PCA：降维/去相关/防过拟合；⑤ Harris：R=det−k·tr²，无尺度不变；⑥ SIFT：四步 + 金字塔/DOG + 128 维。

12图像模式分类IMAGE PATTERN CLASSIFICATION

这章只有三块：模式与模式类、最小距离/模板匹配、贝叶斯分类器。提纲说贝叶斯“可能会在大题中作为关键步骤”，所以推导过程要能默写主干。

12.1 模式与模式类★★

定义模式（Pattern）是描述子的组合；模式类（Pattern Class）是具有某些共同属性的一簇模式。分类就是给未知模式贴上某个模式类的标签。

三种表示形式：向量（定量描述，最常用，x = [x₁, x₂, …, xₙ]T）、串（结构描述，如边界用多边形近似后得到的符号串）、树（结构描述，如卫星图像的分层结构）。

特征向量的例子：由 Hu 不变矩组成的 7 维向量；多光谱遥感图像各波段配准后同一像素级联成的向量；椭圆的 [长轴, 短轴]T。

12.2 最小距离分类器★★★

类原型（均值向量）：mj = (1/Nj)·Σx∈class j x，　j = 1, …, Nc(12.2)
距离：Dj(x) = ‖x − mj‖，　判为 Dj 最小的那一类(12.3)

把距离平方展开可以消掉 ‖x‖²（对所有类相同），得到等价判据：

dj(x) = mjTx − ½ mjTmj，　选最大的 dj(12.4)

决策边界：令 di(x) = dj(x)，得

xT(mi − mj) − ½(mi − mj)T(mi + mj) = 0(12.8)
几何意义（重点）在采用欧氏距离时，两类最小距离分类器的边界是连接 mi 与 mj 的线段的垂直平分线（超平面）：n=2 为直线，n=3 为平面，n>3 为超平面。
例两类均值 m₁ = (2,2)、m₂ = (6,6)，判断 x = (3,4) 属于哪一类，并写出决策边界。
D₁ = √[(3−2)² + (4−2)²] = √5 ≈ 2.24；　D₂ = √[(3−6)² + (4−6)²] = √13 ≈ 3.61。
D₁ < D₂ → 判为第 1 类。
边界：中点为 (4,4)，方向向量 m₂−m₁ = (4,4)，故边界为 x + y = 8（过 (4,4) 且垂直于 (1,1) 方向）。

12.3 模板匹配（二维相关）★★★

当“原型”不是一个均值向量，而是一小块图像模板时，就用相关来匹配：

w ☆ f (x,y) = Σs Σt w(s,t)·f(x+s, y+t)(12.9)
γ(x,y) = ΣΣ[w(s,t) − w̄][f(x+s,y+t) − f̄xy] / {ΣΣ[w−w̄]² · ΣΣ[f−f̄xy]²}1/2(12.10)

归一化相关系数 γ 的取值范围是 [−1, 1]；γ 取得最大值处即为最佳匹配位置。这就是“模板匹配”。除去了均值和能量，所以 γ 对亮度整体偏移和对比度缩放不敏感——这是它比裸相关好用的原因。

模板匹配的优缺点：优点是直观、易实现、光照稳定时效果好、有现成库；缺点是模板尺寸变化或旋转会失效、光照/对比度变化导致误匹配、无法从数据中学习，只适合受控或重复性场景。

12.4 最优（贝叶斯）统计分类器★★★

推导主线（五步）

第 1 步：定义损失。若模式 x 实际属于 ci，却被判为第 j 类，造成损失 Lij。则把 x 判为第 j 类的平均损失（条件风险）为：

rj(x) = Σk=1Nc Lkj·p(ck|x)(12.16)

第 2 步：用贝叶斯公式换掉后验概率。p(a|b) = p(b|a)p(a)/p(b)：

rj(x) = (1/p(x))·Σk Lkj·p(x|ck)·P(ck)(12.17–12.18)

第 3 步：代入 0-1 损失。正确判 0、错误判 1：Lij = 1 − δij（δ=1 当 i=j，否则 0）：

rj(x) = Σk(1−δkj)p(x|ck)P(ck) = p(x) − p(x|cj)P(cj)(12.20–12.22)

第 4 步：得出决策规则。因为 p(x) 对所有类相同，最小化风险等价于最大化 p(x|cj)P(cj)：

dj(x) = p(x|cj)·P(cj)，　若对所有 i ≠ j 有 dj(x) > di(x)，则把 x 判为 cj(12.23–12.24)

第 5 步：说明决策器的作用。决策器（判决器）把特征空间划分成 Nc 个决策区域，区域之间的分界就是决策边界（由 di = dj 解出）。它的作用就是：给定任意一个特征向量，输出它所属的类别，并使平均误判损失最小。

一句话记住贝叶斯后验 ∝ 似然 × 先验。在 0–1 损失下，判为“似然×先验”最大的那一类，可实现最小错误率；一般损失下应最小化条件风险。

高斯模式类下的贝叶斯分类器

一维决策函数：dj(x) = [1/(√(2π)σj)]·e−(x−mj)²/2σj²·P(cj)(12.25)
n 维：p(x|cj) = [1/((2π)n/2|Cj|1/2)]·e−½(x−mj)TCj−1(x−mj)(12.26)
mj = Ej{x}，　Cj = Ej{(x−mj)(x−mj)T}(12.27–12.30)

取对数并假设各类协方差相同，二次项相互抵消，得到线性决策函数（决策超平面）：

dj(x) = ln P(cj) + xTC−1mj − ½ mjTC−1mj(12.34–12.35)
与最小距离分类器的关系各类均为高斯分布、协方差均为 σ²I 且先验相等时，贝叶斯分类器退化为欧氏最小距离分类器；若只共享一般协方差 C，则对应马氏距离，不一定是欧氏距离。不同协方差通常产生二次决策边界，共享协方差时才为线性边界。

本章必会

① 模式=描述子的组合，模式类=具有共同属性的一簇模式；② 最小距离：均值向量 + 欧氏距离，决策边界是垂直平分线/超平面；③ 归一化相关 γ ∈ [−1,1]，最大处最佳匹配；④ 贝叶斯三步推导：平均损失 → 贝叶斯公式 → 0-1 损失 → dj = p(x|cj)P(cj) 取最大；⑤ 决策器的作用：划分决策区域、最小化平均损失。

13.3 范例一：瓶装液位是否装满（习题 11-38）

步骤做法原理 / 目的
1对瓶身图像做高斯滤波抑制传感器噪声，避免后续阈值分割把噪声当目标
2Otsu 阈值分割得二值图液体与空区域的灰度差异显著、直方图近似双峰，Otsu 可自动求最优阈值，分离液体与空腔
3垂直投影 + 连通域分析定位单个瓶子垂直投影的谷点对应瓶间空隙，用于把多瓶图像切成单瓶 ROI，避免相邻瓶干扰

假设与失效① 瓶子规格统一——否则底部/肩部坐标检测偏差，判据失效；② 照明稳定——否则液/空灰度差异波动，Otsu 误判；③ 瓶子无遮挡、无严重倾斜——否则单瓶 ROI 定位受邻瓶干扰、中点不准；④ 图像分辨率足够——否则肩部拐点、液位边界提不出来；⑤ 液体与空腔灰度差异显著——否则阈值分割无法分离两者。

步骤做法原理 / 目的
1提取图像连通分量每个连通域是一个候选斑块（可能含粘连）

5用已知类别的完整椭圆作训练集，分别求三类的均值向量 mj最小距离分类器只需类均值，属于“原型匹配”
6对每个待测斑块算 Dj = ‖x − mj‖，判为 Dj 最小的一类欧氏距离最小 = 最相似；各类两两之间的决策边界是相应均值连线的垂直平分线
假设与失效① 椭圆大小差异明显（三类在长短轴平面上可分），否则最小距离会错分；② 能拿到已知类别的训练样本，否则无法求类均值；③ 斑块完整、不接触边界；④ 无严重粘连（粘连会使长短轴失真，须先腐蚀/分水岭分开）；⑤ 成像比例一致（否则同一椭圆在不同距离下长短轴不同，需先标定）。

14.2 高频易错清单（考前扫一遍）

  • 量化离散的是灰度，采样离散的是坐标。别写反。
  • 图像中心要四舍五入：1281/2 = 640.5 → 641。
  • 空间分辨率必须绑定物理尺寸才有意义。
  • 直方图→图像不唯一（反之才唯一）。
  • 离散直方图均衡通常不会增加灰度级数，只是重映射与合并。
  • 卷积必须翻转核；对称核则相关=卷积。
  • 中值滤波首选治椒盐；对高斯噪声通常不是最优。
  • 锐化 = 原图 减拉普拉斯（中心系数为负时）。
  • Sobel 的 x 核检测竖直边缘（核方向⊥边缘）。
  • 水平直线的频谱是竖直亮线。
  • 用 DFT 实现线性卷积时应补零防混叠；若本意就是周期滤波则按题意处理。
  • ILPF 有振铃，GLPF 没有。
  • 谐波滤波不能用于胡椒噪声（除 0）。
  • 反谐波 Q 符号别记反：正去黑、负去白。
  • 饱和度与白光成反比。
  • HSI 只改 I 可保持 H、S 不变；RGB 三通道同时改常会影响颜色。
  • 彩色单通道噪声可能通过 RGB→HSI 变换耦合到其他 HSI 分量。
  • 腐蚀=收缩，膨胀=扩张；开=先腐后膨。
  • 开运算幂等：重复做没变化。
  • 连通分量提取与 A 相交，孔洞填充与 Ac 相交。
  • 凸壳是最小凸集，H−S 叫凸缺。
  • 灰度腐蚀取 min，膨胀取 max。
  • Canny 的 NMS 是沿梯度方向比较，不是沿边缘方向。
  • 双阈值中高阈值保可靠、低阈值保连续。
  • Otsu 在近似双峰时通常效果好；小目标或单峰时需谨慎。
  • DBSCAN 的密度直达不对称，密度相连才对称。
  • SLIC 的 m 越大越规整，越小越贴边。
  • Hu 矩对平移/缩放/旋转不变，镜像下部分分量会改变符号。
  • Harris 在课件近似下有旋转/光照不变性，缺少尺度不变性。
  • SIFT 描述子是 128 维。
  • 最小距离边界是垂直平分线；贝叶斯取最大。
