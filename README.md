# 数字图像处理 · 期末刷题站

**主站：<https://nstyz.github.io/shua-n-ti/>**

**数字图像处理子站：<https://nstyz.github.io/dip-review/>**

这是 `DIP-刷题手册.md` 的交互版：共 **419 题**（333 道章节自测 + 79 道课本原题 + 7 道 DBSCAN 课件新增题），其中 **173 道单选 + 65 道判断 + 50 道填空 + 65 道简答 + 49 道计算 + 17 道方案设计**。

## 怎么打开

- **推荐**：双击 `启动刷题网站.bat`，会自动启动本地服务器并打开浏览器。进度保存在浏览器 localStorage。
- 也可以直接双击 `index.html`；绝大多数功能可用，但部分浏览器对 `file://` 的本地存储限制更严。
- 单文件版：根目录 `DIP-刷题网站.html`，双击即可，不需要启动服务器。

## 功能

- 章节练习、随机 20 题、按题型专项
- **课本习题索引**：按第 2/3/4/5/6/9/10/11/12 章整理 403 道题号范围，收录 29 道老师解答/补充题 + 50 道新增课本习题
- **复习精讲网页版**：45 页 PDF 内容重排为手机友好的长文阅读页（含课本习题附录），带目录、阅读进度和 PDF 下载；支持**浅色 / 深色 / 杂志风**三种阅读主题
- 单选 / 判断即时判题，答错自动进错题本
- 填空 / 简答 / 计算 / 方案设计：对照参考答案后自评
- 错题本、收藏夹、全局搜索
- 37 题 / 100 分 / 90 分钟模拟卷：客观题自动判分，主观题自评
- 学习统计、连续天数、章节正确率、最近 7 天
- 进度导出 / 导入、深浅色主题、快捷键

## 快捷键

`A–D` / `1–4` 选选项；`←` `→` / `J` `K` 切题；`B` 收藏；`/` 搜索；`?` 帮助。

## 数据说明

题目与解析来自 `DIP-刷题手册.md` 与 `DIP-课本习题索引.md`；原 14 份课程 PDF 保持不变，位于 `00-原始文件备份/`。复习精讲网页版由 `数字图像处理_期末复习精讲.pdf` 同源内容重排，PDF 可在页面内下载。

> 进度只保存在当前浏览器，不会上传。换设备请用「设置 → 导出/导入」。
